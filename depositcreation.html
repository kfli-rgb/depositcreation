三種貨幣供應定義 (M1, M2, M3)

香港金融管理局（金管局）將貨幣供應量分為三個層次。以下公式反映了流動性遞減、範疇遞增的關係。

官方定義與數學公式

M1 (狹義貨幣) 流動性最高
$$M1 = Cp + Dd$$
  • • $Cp$: 非銀行公眾持有的現金
  • • $Dd$: 持牌銀行的活期存款
M2 中等流動性
$$M2 = M1 + Ds_{(lb)} + Td_{(lb)} + NCD_{(lb)}$$
  • • $Ds_{(lb)}$: 持牌銀行的儲蓄存款
  • • $Td_{(lb)}$: 持牌銀行的定期存款
  • • $NCD_{(lb)}$: 持牌銀行發行/公眾持有之可轉讓存款證
M3 (廣義貨幣) 涵蓋最廣
$$M3 = M2 + Td_{(rlb, dtc)}$$
  • • $Td_{(rlb, dtc)}$: 有限制牌照銀行(RLB)及接受存款公司(DTC)的定期存款與發行之可轉讓存款證

存款創造 (Deposit creation)

當公眾將現金存入銀行體系，銀行留存一定比例作為法定儲備後將餘額貸出，透過連鎖貸款與存款，銀行體系能創造出數倍於最初存款的存款總額。

存款創造的三大假設 (Key Assumptions)

  • 1 銀行不持有超額儲備 (No Excess Reserves)：銀行會將所有剩餘儲備全數貸出，超額儲備永遠為 $0$。
  • 2 貸款需求充足 (Sufficient Loan Demand)：公眾對借款有充足的需求，所有貸出的金額都能順利借出。
  • 3 沒有現金流失 (No Cash Drain)：公眾借得款項後，會全數存回銀行體系，不會以現金形式保留在銀行體系外。
若上述任一假設不成立，實際創造的存款額將小於最大可能存款額。

最大可能存款額與存款變動計算器

HKDSE 試題常考亮點：分辨「最大可能總存款額」與「最大可能存款增加/減少額」。

HKDSE 核心解題公式總覽

1. 最大可能總存款額 (Maximum Possible Total Deposits)
$$\text{總存款額 } D = \frac{\text{總儲備 } R}{rr}$$
2. 最大可能存款變動額 (Maximum Possible Change in Deposits)
$$\Delta D = \frac{\Delta R}{rr} \quad \text{或} \quad \frac{\text{超額儲備 } ER}{rr}$$
